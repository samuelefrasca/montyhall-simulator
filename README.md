# 🚪 Monty Hall Simulator

Una simulazione interattiva del classico problema di Monty Hall, realizzata come sito web.

🔗 [Vai al sito live](https://montyhall.pages.dev/)

## Cos'è il problema di Monty Hall?

Il problema di Monty Hall è un celebre paradosso probabilistico. Il giocatore sceglie una porta tra quelle disponibili: dietro una si nasconde un'auto, dietro le altre delle capre. Il conduttore — che sa dove si trova l'auto — apre tutte le porte rimanenti tranne una, rivelando le capre. A questo punto il giocatore può mantenere la sua scelta oppure cambiare porta.

Controintuitivamente, cambiare porta aumenta le probabilità di vincita.
